## CODE OBFUSCATION AND PARTIAL GITHUB PUBLIC CODE

Certain portions of the data extraction and scraping code use obfuscated
identifiers and defensive coding practices. This is intentional to:

1. Prevent unauthorized automated copying of scraping patterns
2. Deter misuse for large-scale Terms of Service violations
3. Protect proprietary pairing algorithms and cross-referencing logic
4. Enable educational use while discouraging production-scale abuse

This obfuscation does NOT hide malicious code. The codebase remains open-source
under AGPL-3.0, and unobfuscated versions are available to legitimate
contributors upon request.
